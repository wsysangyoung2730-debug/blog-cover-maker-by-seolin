## 문서와 작업 보호

Mac은 DocumentGroup, 기본 파일 메뉴·최근 항목·원본 문서 자동 저장을 유지한다. iPad는 WindowGroup으로 편집기를 바로 표시하고 프로젝트 메뉴에서 파일을 불러오거나 저장한다. 기존 버전의 `.seolincover` 파일도 같은 형식으로 읽는다.

iPad 초안은 Application Support/EditorDrafts에 창별 UUID로 보관한다. 저장 요청을 직렬화하고 늦게 끝난 이전 요청이 최신 초안을 덮어쓰지 않게 한다. 손상된 초안을 복구하지 못하면 오류를 알리고 기존 파일을 보존한다. 선택한 프로젝트 파일은 파일 제공자와 읽기를 조정하고 접근 권한을 사용한 뒤 해제한다.

저장 중에는 프로젝트 스냅샷을 사용한다. 저장 취소·실패 때 현재 문서를 유지하고, 저장 시작 후 편집은 미저장 상태로 남긴다. 다른 표지를 열기 전 저장 여부를 확인하며, 문서 전환 시 실행 취소 기록을 분리한다.

사진 기록은 기존 문서 버전 1의 배열과 선택 위치를 그대로 사용한다. 선택한 기록을 삭제하면 다음 사진, 마지막이면 이전 사진을 선택한다. 마지막 개별 사진 기록을 지우면 기본 표지 사진을 사용하며, 기본 사진 기록까지 모두 지우면 사진 없는 상태가 된다. 다른 기록을 지울 때 현재 사진의 확대·위치는 유지한다. 삭제는 실행 취소할 수 있으며 다른 레이어가 사용하는 이미지 데이터는 지우지 않는다.
