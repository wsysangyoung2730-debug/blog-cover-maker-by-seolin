# 검증 기록

검증일: 2026-10-12 (Asia/Seoul)

## 확인한 항목

- Xcode 27.0에서 macOS Debug 빌드 성공.
- Xcode 27.0에서 iPadOS 시뮬레이터용 Debug 빌드 성공.
- macOS 앱 실제 실행, 새 문서 생성, 50종 디자인 라이브러리 표시 확인.
- macOS 한글 문구 입력이 문구 칸과 레이어에 반영되는 것을 확인.
- 프로젝트 저장 대화상자 호출 확인.
- 공통 엔진 XCTest 12개 통과.
- Debug 앱의 `--verify-editor` 검증 경로 통과.

## 자동 검증 범위

1. 50개 디자인·22개 테마·19개 개별 폰트·8개 제목 폰트 옵션.
2. 원본의 7가지 요소 타입 보존.
3. 문구·사진 기록·사용자 폰트 데이터를 포함한 문서 직렬화 왕복.
4. 지원하지 않는 미래 문서 버전 거부.
5. 사진 기록의 앞뒤 이동과 기록 분기.
6. 복제된 글씨의 바인딩 해제와 독립 그룹 생성.
7. 그룹 정렬 시 구성 요소 사이 간격 보존.
8. 크기가 다른 요소의 균등 간격.
9. 레이어 순서 변경 시 다중 선택의 상대 순서 보존.
10. 50개 디자인 렌더링과 글씨 레이아웃의 유효성.
11. 1080×1080 PNG와 투명한 전경 출력.
12. 기본 사진 교체가 공유 사진 틀에 반영되는지 확인.
13. WOFF·WOFF2 실제 파일의 네이티브 폰트 읽기.
14. 앱 문서와 편집 상태 동기화, 문구·테마 전체 실행 취소 및 다시 실행.
15. 테스트 프로젝트 파일과 PNG 세 종류, 50개 디자인 미리보기 생성.

일부 테스트 함수가 여러 항목을 함께 검증한다. 검증용 폰트는 OFL 라이선스와 함께 테스트 자료에 포함한다.

## 검증 한계

- 원본 HTML과 50개 디자인의 픽셀 단위 비교는 수행하지 않았다. Core Text와 브라우저의 글자 기준선·굵기·그림자·흐림에는 차이가 있을 수 있다.
- 모든 메뉴 조합, 모든 크기의 사용자 사진, 모든 외부 폰트를 수동으로 확인한 것은 아니다.
- iPad 실기기와 Apple Pencil의 세부 사용성은 추가 확인이 필요하다.
- 개발 팀 서명, 배포용 아카이브, 공증 및 App Store 배포는 이번 작업 범위에 포함하지 않았다.
- CI는 별도 자동화 설정 이슈에서 연결하며, 원격 실행 결과는 GitHub Actions를 기준으로 확인한다.

## 재현

README의 검증 명령을 실행한다. 시스템 기본 개발 도구가 Command Line Tools를 가리키면 프로젝트 명령 앞에 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`를 지정한다. 전역 Xcode 설정을 바꿀 필요는 없다.
